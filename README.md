# ukraine-car-from-us-calculator

tool to calculate car from us price

http://calc.pp.ua

## Як запустити

```bash
npm start          # Node-сервер на 127.0.0.1:5500 — статика + /api з логуванням у SQLite. Потрібен Node 24+ (node:sqlite)
#                    Тільки локально: сервер роздає config.js із ключем AUTO.RIA і має /api без
#                    автентифікації. Щоб відкрити назовні свідомо — HOST=0.0.0.0 npm start
```

Це **єдиний** варіант, який піднімає `/api`. Сторінки `lots.html`, `searches.html` і `stats.html`
читають дані саме звідти, тому без нього вони показують `Помилка: Failed to fetch (сервер запущено?)`.

Альтернативи — тільки статика, **без** `/api` (калькулятор рахує, але нічого не зберігається,
а сторінки збережених лотів/пошуків не працюють):

```bash
npm run start:py   # python3 -m http.server 5500
make start         # теж python-сервер — не плутати з `npm start`
```

Перевірити, що API живий:

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:5500/api/lots   # має бути 200
```

Можна також відкривати сторінки через VS Code Live Server (:5501). Кожна сторінка спершу пробує
той самий origin (сервер міг віддати її сам, на будь-якому порту), а якщо там `/api` немає —
`http://localhost:5500`; Node віддає CORS для `/api/*`. Але `npm start` при цьому має працювати
паралельно.

Запустити на іншому порту чи з іншою базою (наприклад, щоб щось перевірити й не чіпати робочу БД):

```bash
PORT=5599 DB_PATH=/tmp/scratch.db npm start
```

Для парсингу лотів і запиту ціни AUTO.RIA потрібен `config.js` (gitignored):
скопіюй `config.example.js` → `config.js` і заповни `proxyUrl` та `autoRiaToken`.

## Сторінки

- `index.html` — калькулятор. `?lot=<id>` відкриває його вже заповненим зі
  збереженого лота (кнопка з `lots.html`), без звернення до аукціону.
- `lots.html` — збережені лоти: фільтр і сортування (зокрема за вигодою),
  вигода угоди на картці, повна картка з фото/360°/відео.
- `searches.html` — історія пошуків ринкової ціни.
- `stats.html` — розподіл цін ринку та позиція лота в ньому.
- `resales.html` — перепродажі: вставляєш посилання на оголошення AUTO.RIA,
  з нього береться VIN, за VIN піднімається аукціонна ставка, і рахується
  реальна наварка. Накопичує вибірку, щоб було видно, які ставки реальні.

## Обслуговування БД

```bash
node scripts/backfill-lot-fields.mjs --dry   # що зміниться в data/searches.db
node scripts/backfill-lot-fields.mjs         # записати
```

Добиває поля лотів, які парсер колись не діставав (пробіг, колір, привід,
пошкодження, стан авто, «заводиться», каталізатор, CAT-прапорець, брелок,
примітка до тайтла, гібрид). Бере їх із уже збереженого `raw_json`, тобто без
повторного скрейпу; заповнене не затирає.

```bash
node scripts/resale.mjs --add https://auto.ria.com/uk/auto_..._40023169.html
node scripts/resale.mjs --refresh --limit 25 --dry   # переопитати ціни оголошень
node scripts/resale.mjs --recompute                  # перерахувати landed без мережі
node scripts/resale.mjs                              # TSV усіх спостережень
```

Те саме, що робить `resales.html`, але без сервера. `--refresh` **дописує**
зріз ціни в `resale_price_history`, а не перезаписує: різниця між «просять» і
«дають» видно лише в дельті. `--limit` не косметика — вільний тариф AUTO.RIA
має годинний ліміт близько 25 викликів.

## Як читати цифри угоди

- **Підсумок** — авто на українських номерах, БЕЗ ремонту.
- **Вкладено** — підсумок + ремонт. Саме з ним порівнюється ціна AUTO.RIA:
  там ціна цілого авто, а сюди приїжджає розбите.
- **Вигода угоди** — `(ACV − ремонт) − підсумок`, тобто те саме, але від
  американської оцінки страховика.
- **Макс. ставка за ACV** і **за укр. ринком** — дві стелі. Друга з'являється
  після пошуку ціни й для перепродажу важливіша: ACV зазвичай помітно вищий
  за те, скільки за авто дадуть тут.

## Ставки й константи

Кожна ставка в коді має датований зріз у `docs/`:

| Файл                              | Що покриває                       |
| --------------------------------- | --------------------------------- |
| `docs/customs-rates-baseline.md`  | мито, акциз, ПДВ, митна вартість  |
| `docs/pension-fee-baseline.md`    | збір до Пенсійного фонду (3/4/5%) |
| `docs/auction-fees-baseline.md`   | збори Copart / IAAI               |
| `docs/shipping-rates-baseline.md` | автовоз по США, океанський фрахт  |

Перед тим як міняти будь-яке число — прочитай відповідний baseline. При новому
вимірі додавай **нову колонку**, а не перезаписуй стару: цінність саме в дельті.
