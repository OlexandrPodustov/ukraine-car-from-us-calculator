# Збір на обов'язкове державне пенсійне страхування при першій реєстрації авто

Формула в `assets/js/methods/market.methods.js` (`mreo`, `pensionFeeRate`)
звірена з цим документом.

**Правило:** при повторному вимірі **додавай нову колонку**, не перезаписуй.

Пороги переобчислюються щороку разом із прожитковим мінімумом (закон про
держбюджет). У коді зберігається **сам прожитковий мінімум**
(`subsistenceMinUah` у `core/state.js`), а не готові пороги — щоб оновлення
було в одному числі.

## База

За роз'ясненням ПФУ вартість авто визначається «відповідно до договору
купівлі-продажу, договору міни, **довідки органів митної служби**, акту
експертної оцінки вартості чи інших документів, що підтверджують цю вартість,
**без урахування податку на додану вартість**».

Для імпорту це митна вартість, тобто в коді — `customsBase()`.

⚠️ **Не вирішено.** Частина джерел (buhplatforma) стверджує, що для імпорту до
бази додаються ще мито й акциз, і наводить приклад, де саме через це ставка
піднімається з 3% на 4%. Роз'яснення ПФУ цього не підтверджує й не спростовує.
Різниця між двома прочитаннями на типовому авто — одна сходинка ставки, тобто
до ~1% вартості. Потребує підтвердження в брокера.

## Валюта

Пороги в законі — **у гривнях**, база в калькуляторі — в доларах. Тому база
переводиться в гривні за курсом НБУ (`usdUah`, тягнеться в `rates.service.js`
разом з EUR/USD; дефолт 44.7 на випадок недоступності API).

## Що було до 2026-08-19

```js
if (autoPrice < 13300) (3 % від(autoPrice + auctionFee + 1000)) + 25;
else if (autoPrice < 23500) (4 % від(autoPrice + auctionFee + 1000)) + 25;
else (5 % від(autoPrice + auctionFee + 1000)) + 25;
```

Чотири розбіжності із законом:

1. **Пороги $13 300 / $23 500** — з коміту 2021 року, без джерела, у доларах,
   тоді як закон задає їх у гривнях через прожитковий мінімум. Ані ПМ, ані курс
   з того часу не оновлювались.
2. **Пороги звірялись із ціною з молотка**, а не з базою збору. Авто за $12 000
   з доставкою й зборами має базу ~$17 000 — це вже інша сходинка.
3. **База — плоский проксі `+1000`** замість реальної митної вартості. Той самий
   проксі вже прибрали з `customsBase()` 2026-08-17, але в цьому методі він
   лишався: у розрахунку співіснували дві різні «вартості авто».
4. **Електромобілі оплачували збір**, хоча звільнені від нього прямою нормою.

Хвіст `+ 25` — недокументована фіксована добавка з того ж коміту 2021 року;
прибрана разом із рештою (жодне джерело її не згадує).
