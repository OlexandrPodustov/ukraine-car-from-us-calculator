# Що насправді рахує `/auto/average_price` — зонди та зрізи

Скрипт: `node scripts/ria-average-price-probe.mjs [--append]` (9 викликів, зупиняється
на першій відмові по погодинному ліміту). Кожен зонд відрізняється від сусіднього
рівно одним фільтром — так видно, чи фільтр взагалі впливає на вибірку.

**Правило:** кожен повторний прогін — **новий зріз нижче**, старі не перезаписуємо.

---

## Навіщо це

`lookupUkrainianPrice()` бере `interQuartileMean` з цього ендпоінта як «ціну на
українському ринку», і саме з нею порівнюється собівартість пригону. Якщо вибірка
не та, за яку ми її маємо, весь висновок «вигідно / невигідно» зсунутий.

Підозри, зафіксовані **2026-08-17** (перевірити зондами):

1. **`n` більший за кількість активних оголошень на сайті.** Активних Porsche 911
   на AUTO.RIA (усі роки, усі статуси) — **80**
   (`auto.ria.com/uk/search/?...brand=59&...model=539`), а відповіді API давали
   `n=144`. Тобто або вибірка ширша за модель, або в неї входять неактивні/архівні
   оголошення.
2. **Рік фільтрується непослідовно.** У кеші браузера лежали результати
   `bmw|m340i|2020` → `n=2253` і `bmw|m340i|2023` → `n=1669` (обидва → базова модель
   «3 Series»), тоді як усіх активних 3 Series на сайті **4050**. 2253 оголошення на
   вікно 2019–2021 — це 56% усього парку 3 Series, що неправдоподібно.
3. **Розмитнені vs «під пригон».** Порівнювати собівартість пригону треба з авто, які
   вже в Україні й розмитнені (`customs_cleared=1&abroad=0` на сайті). Якщо API
   змішує їх з «під пригон», ринкова ціна занижена системно. Зонди 6–7 перевіряють,
   чи ендпоінт узагалі реагує на `custom=1` та на імена параметрів із сайту.

Довідково (з сайту, 2026-08-17): Porsche 911 — 80 активних, найдешевше $38 000
(2003 р.); BMW 3 Series — 4050 активних.
